### `graph_capture.py` (design §3.1-3.2)

1. `ScopeOwner = tuple[int, str]` meaning `(global_layer_id, scope)`; `None` is the outside owner.
2. A `GraphQueries` protocol (the CUDA side, injectable): `current_stream() -> int`, `capture_graph(stream: int) -> int` (the graph being captured into on that stream; raises a clear error when the stream is not capturing), `graph_nodes(graph: int) -> list[int]`, `node_type(node: int) -> str`, `kernel_launch(node: int) -> KernelLaunch` (`name` raw, `grid` and `block` as 3-tuples of int), `dependencies(node: int) -> list[int]`, `node_id(node: int) -> int` (CUPTI id), `demangle(name: str) -> str | None`.
3. `CudaGraphQueries`: the real implementation. Lazy imports. Stream: `torch.cuda.current_stream().cuda_stream`. Capture graph: `cudaStreamGetCaptureInfo` (runtime). Nodes: `cudaGraphGetNodes`. Type: `cudaGraphNodeGetType`, mapped to the names `kernel`, `memcpy`, `memset`, `event_record`, `event_wait`, `empty`; any other type raises with the numeric type. Kernel params: driver `cuGraphKernelNodeGetParams`; name from `cuFuncGetName(func)` when `func` is set, otherwise `cuKernelGetName(kern)` when `kern` is set, otherwise raise. Dependencies: `cudaGraphNodeGetDependencies`. CUPTI ids: `cuptiGetGraphNodeId` through ctypes. Demangle: `__cxa_demangle` from libstdc++ through ctypes, freeing the returned buffer; `None` when the status is non-zero. Every CUDA/CUPTI error raises with the API name and error code. The libcupti library is the single `libcupti.so*` path mapped in the process (`/proc/self/maps`), which is the one Kineto loaded; zero or several distinct paths raise. Share this resolution with the clone recorder.
4. `CuptiCloneRecorder`: context manager. `__enter__` subscribes (`cuptiSubscribe`) and enables `GRAPHNODE_CLONED` in the resource domain (`cuptiEnableCallback`). Error 39 raises a message saying another CUPTI subscriber (for example an active torch.profiler/Kineto session) holds the slot and that the recorder must run before any profiler session. `__exit__` disables and unsubscribes its own subscriber only, then raises any error the callback stored. The callback ignores other domains and callback ids; for `GRAPHNODE_CLONED` it reads `CUpti_ResourceData`, takes `CUpti_GraphData` from `resourceDescriptor`, and appends `(clone_node_id, original_node_id)` from `cuptiGetGraphNodeId(node)` and `cuptiGetGraphNodeId(originalNode)`. A null descriptor, a null node, or a failed id query is stored (a ctypes callback cannot raise) and raised at exit. Keep a reference to the CFUNCTYPE object for the subscription lifetime. Make the payload parsing a separate function taking the `cbdata` pointer and an id-query callable, so the tests can drive it with real ctypes structs in memory. The CUPTI library object is injectable for tests.
5. `GraphCaptureRecorder(queries, eager_scope_runner)` where `eager_scope_runner(owner: ScopeOwner | None, fn: Callable[[], Any]) -> Any` is supplied by the integrator.
   - `install(graph_class, breakable_class)`: context manager that patches, at class level, `graph_class.capture_begin`, `graph_class.capture_end` and `breakable_class.add_eager`, and restores the originals on exit (also on error).
   - Patched `capture_begin(self, *args, **kwargs)`: open a capture record with an ordinal, kind `breakable_segment` when `breakable_class.current()` is not `None` (with that Breakable capture's ordinal, assigned on first sight) and `graph` otherwise, and the origin stream `queries.current_stream()`; then call the original. Opening a capture while one is open raises.
   - Patched `capture_end(self)`: sweep, close the record, then call the original (which instantiates and fires the clone callbacks).
   - `scope(owner)`: context manager. On enter: sweep if a capture is open, record a scope entry `(capture ordinal, owner, parent)` when a capture is open (parent = current stack top or `None`), push. On exit (in `finally`): sweep if a capture is open, pop.
   - Sweep: `graph = queries.capture_graph(origin_stream)`, nodes not yet seen in this capture (seen set per capture, by handle) get owner = stack top (or `None`); record per node: capture ordinal, CUPTI node id, type, and for kernels raw name, demangled name, grid, block; for every node the CUPTI ids of its dependencies. Assign CUPTI ids to all new nodes before resolving dependencies, since a new node can depend on another new node.
   - Patched `add_eager(capture_self, fn)`: owner = stack top at registration; call the original; check `capture_self.segments[-1] is fn` (raise otherwise); replace that entry with a wrapper that calls `eager_scope_runner(owner, fn)`; record `(breakable capture ordinal, segment index, owner)`; return the original result. The capture-time call of `fn` is not wrapped.
   - `record(clones) -> CaptureRecord`.
6. `CaptureRecord`: frozen dataclass with `to_json() -> dict` and `from_json(dict)`; the JSON is the raw-record format (plain lists and ints/strings, owners as `[layer, scope]` or `null`):
   ```
   {"captures": [{"ordinal", "kind", "breakable_capture", "origin_stream"}],
    "nodes": [{"capture", "node_id", "node_type", "kernel_name", "kernel_name_demangled",
               "grid", "block", "dependencies", "owner"}],
    "scope_entries": [{"capture", "owner", "parent"}],
    "eager_breaks": [{"breakable_capture", "segment_index", "owner"}],
    "clones": [{"node_id", "original_node_id"}]}
   ```
   Node ids are unique across the record (fail on a duplicate when building or loading).

### `graph_replay_trace.py` (design §3.3)

1. `STEP_ANNOTATION_PREFIX = "frontier_dsa_step"`, `step_annotation_name(step_index)` (`frontier_dsa_step|<n>`), `parse_step_annotation(name) -> int | None` (malformed names with the prefix raise).
2. `attribute_replay_trace(events, record: CaptureRecord) -> ReplayAttribution`, one pass in `O(n log n)`:
   - Step ranges: `user_annotation` events parsed by `parse_step_annotation`, per `(pid, tid)`; overlapping step ranges on one thread raise.
   - Graph activities: `kernel`, `gpu_memcpy`, `gpu_memset` events whose `args["graph node id"]` is positive. Their correlation selects a `cuda_runtime` event whose name starts with `cudaGraphLaunch`; the launch's start on its thread selects the step range; launches outside every step range are counted in `unattributed_launch_count` and not attributed. The node id is mapped through the clone map to a captured node. If it is not a clone id, raise; the message says whether the id is a captured node id itself. All activities of one launch must belong to one capture, every kernel/memcpy/memset node of that capture must appear exactly once in the launch (otherwise raise: incomplete trace or ambiguous mapping), and the owner is the captured node's owner. For kernels, the event name must equal the captured raw name or demangled name, and `args["grid"]` / `args["block"]` must equal the captured grid / block; mismatches raise with both values.
   - Eager kernels (`kernel` events with no positive graph node id): correlation selects a `cuda_runtime` or `cuda_driver` launch; the innermost scope range (`parse_annotation_name` from `dsa_kernel_trace`) containing the launch start on the launch's thread owns it. Scope ranges may nest; partially overlapping ranges on one thread raise. A scope key may have several ranges in one step; their kernels add. A launch inside a step range but in no scope range is owned by the outside owner of that step; a launch outside every step range is counted in `unattributed_launch_count`. Eager memcpy/memset are not costed and need not be attributed.
   - Container scopes: owners that appear as `parent` in `record.scope_entries`, and scope keys `(layer, scope)` whose range encloses another scope range. A kernel owned directly by a container raises (check A2).
   - Scope set per step: the owners of the scope entries of every capture launched in the step, the owners of the nodes launched, and every scope range of the step. Scopes with no kernel in the step have time 0.0 and count 0.
   - `scope_times: dict[ScopeKey, ScopeKernelTime]` summing kernel durations (`dur`, microseconds, reported in ms like `dsa_kernel_trace`) and counts; memcpy and memset are excluded from costs.
   - `layer_windows: dict[tuple[int, int], tuple[float, float]]`: per `(step_index, global_layer_id)`, first kernel start to last kernel end over all streams, over kernels owned by scopes of that layer.
   - Graph gaps: for each graph kernel, resolve its captured dependencies, passing through `event_record`, `event_wait` and `empty` nodes recursively (memoized), to kernel/memcpy/memset nodes; the gap is the kernel start minus the latest end of those nodes' activities in the same launch; a kernel with no such dependency has gap `None`.
   - `intervals: tuple[ReplayInterval, ...]` for every attributed activity (graph and eager kernels, graph memcpy/memset): `step_index`, `owner`, `kind` (`graph`/`eager`), `activity` (`kernel`/`memcpy`/`memset`), `name`, `start_us`, `end_us`, `stream`, `graph_id`, `graph_node_id`, `original_node_id` (or `None`), `correlation`, `graph_gap_us` (or `None`).
   - `outside_kernel_counts: dict[int, int]` per step, and `unattributed_launch_count: int`.
